AquaAd Studio — 3D Carton Ad Preview

Files
- index.html: standalone interactive browser prototype.

How to run
1. Keep an internet connection available (Three.js is loaded from jsDelivr).
2. Open index.html in a recent version of Chrome, Edge, Firefox, or Safari.
3. Tick any combination of the seven carton sides (they do not need to be consecutive). Use Select all or Clear selection if helpful.
4. Select a chosen side and upload a JPG, PNG, or WEBP image. Each side can have different artwork.
5. Drag the carton to rotate it, use the mouse wheel to zoom, or use the controls to pause rotation, reset, and save a PNG preview.

Prototype notes
- The front panel displays the ad enquiry contact +91 9191919191 until an image is uploaded to that panel.
- Advertisers can independently choose any combination of the seven sides. Unselected sides keep AquaAd branding; uploaded artwork is retained as a draft if its side is later deselected.
- Uploaded images are processed locally in the browser. This prototype does not send images to a server or store customer artwork.
- The 3D shape is an illustrative 500 ml gable-top carton concept, not a manufacturer-approved print dieline. Confirm dimensions, folds, seals, print-safe areas, and cap placement with the carton supplier before production.
- No account system, payment, cloud upload, quote workflow, or backend has been connected yet.
